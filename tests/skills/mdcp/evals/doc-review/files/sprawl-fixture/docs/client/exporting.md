# Exporting reports

1. Open **Reports** and pick a date range.
2. Select **Export** and choose CSV or PDF.
3. Download the file from the link in the notification.

Exported reports are kept for 30 days after they are generated. After 30 days the export file is deleted and the download link stops working, so anyone who needs a report for longer must save a copy to their own storage before the period ends.
