# FAQ

## Why can't I edit an issued invoice?

Issued invoices are locked so the amount a customer was sent never changes. Issue a credit note instead.

## Where did the old export button go?

Previously, before the 1.3 release, exports lived under **Invoices → More → Export** and only produced CSV.
In 1.3 we moved them to **Reports** and added PDF. The old menu entry was removed in 1.4.
