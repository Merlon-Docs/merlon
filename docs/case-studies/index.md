# Case studies

Projects that moved their documentation into Merlon Docs, written up while the work goes on: how the work is running, what has come out of it so far, and what has been tried along the way. Each case study opens with its status.

The first, still in progress, is the [ncurses documentation migration](./ncurses/index.md). Its source is on GitHub at [betsalel-williamson/ncurses](https://github.com/betsalel-williamson/ncurses), and the edition it produces is published at <https://betsalel-williamson.github.io/ncurses/>.
