# About this guide

**Audience:** coding agents and technical readers who need to understand what mdcp does — commands, design constraints, and migration from legacy tooling.

This is the **product** guide (`docs/features/`): capabilities and behavior of the tool itself. Begin with [Overview](./overview.md) for the high-level pipeline and code map, then use the sections below for specifics. The [Glossary](../glossary/index.md) defines shared terms.

**Belongs here:** what the product does — commands, design/ADRs, contracts, acceptance criteria.  
**Does not belong here:** maintainer runbooks, live skill evals, contributor setup, or consumer how-to tutorials (those are [Developer](../developer/index.md) or client guides).

For how to contribute to this repository (setup, tests, changesets, releases, and **Agent Skill development**), read the [Developer Guide](../developer/index.md). Do not place maintainer or skill development documentation in this features guide.

Consumer adoption docs compile separately into npm package READMEs under `docs/client-cli/` and `docs/client-core/`. The root [README](../../README.md) compiles from `docs/repo-readme/`.

Guide placement rules for skill workflows: [Skill workflows](./protocol/skill-workflows.md#three-tier-authoring-obligations).
