# idea mitosis

**Idea mitosis** is splitting a documentation shard when it grows a second responsibility (see [shard single responsibility](./shard-single-responsibility.md)). Also split it when reading the file alone misleads. After a split, update the guide index and cross-link the daughter shards.

Do not split only because a file is long. Prefer one primary concern per shard.

See [Shard single responsibility and idea mitosis](../features/protocol/shard-srp-and-mitosis.md).
