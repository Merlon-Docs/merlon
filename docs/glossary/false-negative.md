# false negative (type II error)

A [review outcome](./review-outcome-matrix.md) where the doc needed to change but the review left it as it was. The review missed a real problem, or dropped a claim about it, so the error stays in the doc. Statistics calls this a **type II error**.

A false negative leaves no edit behind, so a later review, a reader, or a bug report finds it. [Review outcomes](../features/system/workflows/doc-review.md#review-outcomes) in the doc-review workflow spec shows all four outcomes.
