# orphan

An **orphan** is a top-level shard in a [guide](./guide.md) directory that the guide's [manifest](./manifest.md) does not link. [Orphan check scope](../features/manifest-compile-order.md#orphan-check-scope) in Manifest compile order specifies the check and which manifest links count, including the `compile.sectionsHeading` rule and the [file-name fallback](../features/manifest-compile-order.md#linked-shards-and-the-file-name-fallback).
