# archetype

An **archetype**, or battery type, is a documented bundle of guide layout, glossary seeds, optional prompts and extension pointers for one project class. The default, the Code Repository Archetype, is the four [guide tiers](./guide-tier.md) that [Default guide layout](../features/system/merlon-docs-1.0-spec.md#2-default-guide-layout-code-repository-archetype) defines. A team can define its own for another documentation system, as [Archetypes](../features/system/extensions-and-archetypes.md#archetypes-battery-types) says.

The adoption archetypes in [Personas and priority tiers](../features/personas-and-priority-tiers.md#adoption-archetypes), such as Learner and Author, are reader goals, not layouts.
