# false positive (type I error)

A [review outcome](./review-outcome-matrix.md) where the doc didn't need to change but the review changed it. The review flagged a problem that wasn't there, so the edit was needless and can introduce an error into a correct doc. Statistics calls this a **type I error**.

The [evidence check](./evidence-check.md) guards against it: a claim edits a doc only when the source it was checked against matches the claim. [Review outcomes](../features/system/workflows/doc-review.md#review-outcomes) in the doc-review workflow spec shows all four outcomes.
