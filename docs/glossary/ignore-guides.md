# ignoreGuides

**`ignoreGuides`** is a list of guide names on the **compiling** guide, under `compile.crossGuideLinks.ignoreGuides`. Cross-guide links to a listed guide keep pointing at the source shard instead of rewriting to a `#slug` target. A link to a shard the compiling guide stitches can still take its in-document anchor. [Same compiled output preference](../features/compile-pipeline/cross-guide-links.md#same-compiled-output-preference) says when the cross-guide pass gives it one. [`ignoreGuides` interaction](../features/compile-pipeline/publish-relative-links.md#ignoreguides-interaction) says how compile rebases a kept path, and when a `./` or bare link to a stitched shard takes `#slug`. The listed guide stays in `compileOrder` and in the link index.

Read [Cross-guide link rewriting](../features/compile-pipeline/cross-guide-links.md) for how other links rewrite, and the [publish-only link policy](../features/link-validation.md#publish-only-link-policy) for how link validation treats kept shard paths.
