# GFM

**GitHub Flavored Markdown** ([spec](https://github.github.com/gfm/)) is CommonMark plus GitHub extensions (tables, task lists, fenced code). Not Pandoc, LaTeX, or wikilinks.

MDCP’s authored format contract is GFM, but heading recognition is an **ATX subset**: setext headings are not recognized. See [GFM scope](../features/design-constraints/gfm-scope.md#headings).
