# WIIFM

**What's In It For Me**: the reader's benefit, stated before mechanics or toolchain detail. On mdcp landing pages, each [adoption archetype](../features/personas-and-priority-tiers.md#adoption-archetypes) gets one WIIFM line, and each line follows the [claim tiers](../features/protocol/benefit-claims-and-evidence.md#claim-tiers) in Benefit claims and evidence.
