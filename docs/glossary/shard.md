# shard

A **shard** is a small Markdown file that owns one topic. In MDCP, authors edit shards; `compile` stitches them into [compiled guides](./compiled-guide.md), such as a package README. Shards are the source of truth, so do not hand-edit generated files.

Think “one concern per file” so people and agents can load only what the task needs. Related: [shard single responsibility](./shard-single-responsibility.md). Deeper model: [Overview](../features/overview.md).
