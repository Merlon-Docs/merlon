# check

**`merlon check`** is Merlon Docs’ validation gate, run locally and in CI before a merge. It validates the documentation **system** (compile output, cross-links, orphans, optional lint and prose rules) — not whether product claims are factually correct. See [Check gate](../features/check-gate.md) for what it runs and [Documentation and software reliability](../features/system/documentation-and-reliability.md#where-merlon-docs-fits) for where human and agent review fit.
