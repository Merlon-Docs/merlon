# shard single responsibility

**Shard single responsibility** means each durable documentation shard owns one primary concern, for one [guide tier](./guide-tier.md), serving one job: explain, instruct how-to, or define and look up. A shard should have one main reason to change.

See [Shard single responsibility and idea mitosis](../features/protocol/shard-srp-and-mitosis.md) and [idea mitosis](./idea-mitosis.md).
