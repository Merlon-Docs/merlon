# Learn More

Go deeper by goal:

- **Integrate Merlon Docs into repo scripts and CI:** the [CLI consumer guide](../../packages/merlon-docs-cli/README.md) for `@merlon-docs/merlon-docs-cli`, and the [Core API guide](../../packages/merlon-docs-core/README.md) for `@merlon-docs/merlon-docs-core` when a script calls the library.
- **Try Merlon Docs before mastering every CLI flag:** the [getting-started workflow](../features/system/workflows/getting-started.md) that the bootstrap prompt starts. The [Agent Skill](../features/agent-skill.md) spec and the skill's page on [skills.sh](https://skills.sh/Merlon-Docs/merlon) describe the skill itself.
- **Own content, not the toolchain:** the [Overview](../features/overview.md) of how Merlon Docs fits together, and the [usage model](../features/system/usage-model.md) for how people and agents read shards.
- **Evaluate or sponsor adoption:** the [vision and roadmap](../features/system/00-vision-and-roadmap.md), and the [benefit claims policy](../features/system/benefit-claims-and-evidence.md).

The [docs site](https://merlon-docs.github.io/merlon/) publishes the Agent Skill and its workflows (Parts 1 and 2), the CLI guide (Part 3), the concepts, the library API, and the glossary as web pages.
