# Learn More

Go deeper by goal:

- **Integrate mdcp into repo scripts and CI:** the [CLI consumer guide](../../packages/mdcp-cli/README.md) for `@bwilliamson/mdcp-cli`, and the [Core API guide](../../packages/mdcp-core/README.md) for `@bwilliamson/mdcp-core` when a script calls the library.
- **Try mdcp before mastering every CLI flag:** the [getting-started workflow](../features/protocol/workflows/getting-started.md) that the bootstrap prompt starts. The [Agent Skill](../features/agent-skill.md) spec and the skill's page on [skills.sh](https://skills.sh/betsalel-williamson/mdcp) describe the skill itself.
- **Own content, not the toolchain:** the [Overview](../features/overview.md) of how MDCP fits together, and the [usage model](../features/protocol/usage-model.md) for how people and agents read shards.
- **Evaluate or sponsor adoption:** the [vision and roadmap](../features/protocol/00-vision-and-roadmap.md), and the [benefit claims policy](../features/protocol/benefit-claims-and-evidence.md).

The [docs site](https://betsalel-williamson.github.io/mdcp/) publishes the CLI guide, the concepts, the library API and the glossary as web pages.
