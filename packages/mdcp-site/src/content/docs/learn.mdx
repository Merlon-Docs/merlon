## 1 · Understand the problem

Software failures cost hundreds of billions to trillions of dollars a year, and documentation is one
of the causes a team can act on. When agents write much of the change, docs also break in a few
familiar, structural ways.

## 3 · Try it

Install the skill in your agent, or the CLI in your repository, and run a compile. The quick start
takes a repository from no shards to a passing check.

```bash wrap
npx skills add betsalel-williamson/mdcp --skill mdcp
```

## 4 · Measure it

How much context does an agent load? This repository measures a whole compiled guide against one shard. The figures are rough estimates. Every model and system tokenizes differently, so compare the
sizes with each other, not with a bill.

<ContextSizes />

Measure your own repository with `pnpm bench:context-size`, and switch the tokenizer to match your stack:

- `--tokenizer o200k_base` is the default. `cl100k_base`, `p50k_base` and the other gpt-tokenizer encodings work the same way.
- `--tokenizer chars4` skips the tokenizer and divides characters by four.
- `--tokenizer-module ./count.mjs` loads your own counter, a module that exports `countTokens(text)`.

```bash wrap
pnpm bench:context-size -- --tokenizer cl100k_base
```
