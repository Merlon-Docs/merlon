The getting-started workflow gains a "brownfield, non-Markdown" branch for docs that Sphinx, MkDocs or Antora already builds: no `docs/` scaffold, an out-of-tree config with `sources`, a project-local extension skill, and `merlon check --no-compile` and `merlon review --no-compile` only.
