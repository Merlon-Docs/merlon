The core README keeps the API reference and what a hook author or config author uses: the compile hooks overview, the extension pattern and each built-in hook. The compile pipeline specs moved to a Compile pipeline group in the Features Guide, under `docs/features/compile-pipeline/`. The group lists Link passes, Path lookup order, Cross-guide link rewriting, Publish-relative link rewriting and Tables after link rewriting, and the core README links them. Its `#link-passes`, `#path-lookup-order`, `#guidedir-misaligned-with-shard-tree`, `#cross-guide-link-rewriting`, `#publish-relative-link-rewriting` and `#tables-after-link-rewriting` anchors are gone, with the anchors of their subsections. A link to one of them should point at the same heading in the moved shard. The guideDir section is now Guide directory apart from its shards, in Path lookup order. The move also renamed or dropped these subsections. In Cross-guide link rewriting, the section with the old anchor `#cross-guide-purpose` is now Guide link index, so a link to it should point at `cross-guide-links.md#guide-link-index`, and its dead-anchor and wrong-heading limits are under `#link-index-limits` there. The section with the old anchor `#default-_build-outputs-and-transitive-targets` is gone, since it didn't add a rule, and a link to it should point at `#same-compiled-output-preference`, the rule it pointed at. In Publish-relative link rewriting, the section with the old anchor `#why-this-pass-exists` is now Shard-relative paths and the one with `#repo-dogfood-examples` is now Examples from this repository, so a link to them should point at `publish-relative-links.md#shard-relative-paths` and `publish-relative-links.md#examples-from-this-repository`. The group also has a Fence scan shard and a Section slugs shard, split from the stripAnchors spec and the cross-guide spec.

The CLI README links the moved shards where it linked those core README sections.
