## Insert catalog

Store captioned inserts in typed libraries under the docs root (`diagrams/`, `tables/`, `figures/`, `media/`, `inserts/`). Shard bodies can be tables, prose, Mermaid, or media embeds. Shards link with normal markdown; compile inlines the first reference per guide and back-links the rest.

Each first reference below has a paragraph of its own, since compile replaces it with the insert's heading and body. The catalog table after them links to each insert again, and compile turns those links into back-links.
